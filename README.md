# City Apps

One repository, one folder per game. Each game is served from its own folder on GitHub Pages.

| Game | Folder | Live at |
| --- | --- | --- |
| Clock Rate | `clockrate/` | https://zachyj7.github.io/city-apps/clockrate/ |
| Hourfall | `hourfall/` | https://zachyj7.github.io/city-apps/hourfall/ |
| Big Money | `bigmoney/` | https://zachyj7.github.io/city-apps/bigmoney/ |
| Jensen Games | `jensengames/` | https://zachyj7.github.io/city-apps/jensengames/ |

`.github/workflows/pages.yml` copies each game's `www/` into the site whenever `main` changes.
